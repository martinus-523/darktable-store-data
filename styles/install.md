# How to Install darktable Styles
Once you downloaded the .dtstyle file from this website,
it should be installed into darktable before it can applied on an image.

## Step 1: Open the styles module
Start darktable and switch to the **lighttable** view (press `L` if you're in the darkroom).
In the panel on the right-hand side you'll find a module called **styles**.
Click its header to expand it if it's collapsed.

## Step 2: Import the file
Click the **import** button inside the styles module.
A file dialog opens — browse to the .dtstyle file you downloaded, select it, and confirm.
The style now appears in your styles list.
That's the whole installation: the style is saved in darktable's own database,
so you can delete the downloaded file afterwards if you like.

## Step 3: Apply it to a photo
Select one or more photos in the lighttable, then double-click a style in the list to apply it.
Hovering over a style's name gives you a quick preview on the selected image, so you can try different looks before committing. You can also apply styles while editing in the darkroom view.

## Good to know
Applying a style adds its edits to the photo's history stack,
so nothing is destroyed — you can always undo it or compress the history later.
And once you're comfortable, try the **create** button in the same module:
it turns your own edits into a style you can reuse or export as a .dtstyle to share with others.
