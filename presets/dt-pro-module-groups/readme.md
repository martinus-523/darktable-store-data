# DT Pro — darktable Module Preset

A curated module preset for [darktable](https://www.darktable.org/) that provides a clean, professional
module selection built around the modern **scene-referred** workflow — the current standard for achieving optimal results.

Obsolete modules such as *Base Curve* and *Shadows and Highlights* are hidden, so you adopt contemporary editing
techniques from day one.

> Source: [darktable.info — Preset Module DT Pro](https://darktable.info/en/preset-module-dt-pro/)

## Module Organization

### Basics

Foundation modules for brightness, color, and composition:

| Module | Purpose |
| --- | --- |
| AgX | Modern tone mapping with natural highlight rendering |
| Color Balance RGB | Primary color and contrast control tool |
| Contrast Equalizer | Controls image crispness and detail emphasis |
| Color Calibration | Ensures color accuracy and removes casts |
| Crop | Frame selection and aspect ratio adjustment |
| Tone Equalizer | Brightens shadows and darkens highlights naturally |
| Exposure | Initial global brightness adjustment |
| Rotate and Perspective | Horizon straightening and geometric correction |
| Raw Chromatic Aberrations | Early-stage color fringe removal |
| White Balance | Technical color temperature foundation |

### Details

Technical corrections and creative refinements:

| Module | Purpose |
| --- | --- |
| Watermark | Logo and text insertion |
| Vignetting | Artistic corner darkening or brightening |
| Grain | Film grain simulation |
| Color Equalizer | Selective color adjustments by hue and saturation |
| Diffuse or Sharpen | Advanced sharpening and local contrast |
| Retouch | Spot and blemish removal |
| Chromatic Aberrations | Secondary color fringe correction |
| Lens Correction | Distortion and vignetting compensation |
| Denoise (profiled) | Camera-specific noise reduction |
| Highlight Reconstruction | Recovery of blown-out highlights |

## Why Scene-Referred?

The preset focuses strongly on darktable's modern scene-referred workflow, which handles high dynamic range naturally and delivers more realistic tonal rendering than the legacy display-referred approach. By hiding outdated modules, DT Pro keeps the interface focused on the tools that matter today.
