# How to Install a darktable preset
Once you downloaded the .dtpreset file from this website,
it should be installed into darktable before it can be used.

## Step 2: Open the preferences
Start darktable and click the **gear icon** in the top panel to open the preferences window.
In the list of tabs, choose **presets**.
This tab shows all presets currently on your system, neatly grouped by module.

## Step 3: Import the file
Click the **import** button at the bottom of the window, browse to your
downloaded .dtpreset file, select it, and confirm. Done — the preset is now
stored in darktable's database, so the downloaded file itself is no longer needed.
You don't have to tell darktable which module it belongs to;
that information is saved inside the file.

## Step 4: Use the preset
Open a photo in the **darkroom** view and go to the module the preset was made for.
Click the small **hamburger menu** (the ≡ icon) in the module's header
and you'll find your new preset in the list — one click applies it.
From this same menu you can also save your own settings with "store new preset...".
