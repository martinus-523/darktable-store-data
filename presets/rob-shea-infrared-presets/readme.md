# darktable Infrared Presets

A collection of presets by [Rob Shea](https://www.robsheaphotography.com/) to quickly color-swap infrared images in [darktable](https://www.darktable.org/), using two different approaches:

- **Channel-mixer color swaps** — via the *Color Calibration* module (`channelmixerrgb_IR_swap_*`), including the classic red/blue swap and variants that mix green into the blue or red channel, or split it between both.
- **Hue-shift swaps** — via the *Color Balance RGB* module (`colorbalancergb_IR_hue_shift_*`), shifting hue in 30° steps from −30° up to +180° for more gradual, creative color remapping.

> Source: [robsheaphotography.com — darktable Infrared Presets](https://www.robsheaphotography.com/darktable-infrared-presets/)

## Presets

| Preset | Module | Purpose |
| --- | --- | --- |
| `channelmixerrgb_IR_swap_RB` | Color Calibration | Classic red/blue channel swap |
| `channelmixerrgb_IR_swap_RB_G-B` | Color Calibration | Red/blue swap, green mixed into blue |
| `channelmixerrgb_IR_swap_RB_G-R` | Color Calibration | Red/blue swap, green mixed into red |
| `channelmixerrgb_IR_swap_RB_G-Split` | Color Calibration | Red/blue swap, green split between red and blue |
| `colorbalancergb_IR_hue_shift_-030` … `+180` | Color Balance RGB | Hue rotation in 30° steps (−30° to +180°) |
